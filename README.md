## 製品概要 

### 背景(製品開発のきっかけ、課題等）
受験期の子供を持つ親は、子供に勉強へ集中してほしいと考えており、勉強の妨げになるものをできるだけ減らしたいと考えています。一方、子供自身も勉強に集中したいと思っていても、スマートフォンを自分の意志で手放すことが難しく、なかなか勉強に取り組めないという課題があります。
また、スマホに制限をかけたいけど、勉強用のアプリもあるので制限をかけられないという親もいます。
そこで私たちは、テストや受験日に向けて、スマートフォンの利用可能時間を段階的に減らしていくアプリ「Slope」を開発しました。


### 製品説明（具体的な製品の説明）
このアプリでは、親が利用時間の目標を設定し、登録されたテスト日程に合わせて利用上限が自動的に調整されます。また、テスト終了後には利用時間が一時的に回復する仕組みを取り入れることで、娯楽の時間を完全になくすことなく、次のテストに向けて再び少しずつ利用時間を減らしていきます。
さらに、親は子供の利用状況を確認でき、子供自身も利用割合を確認することで、スマートフォンの使いすぎを意識できるようにしています。
スマートフォンを急に使えなくするのではなく、無理のないペースで利用時間を減らすことで、親子双方のストレスを軽減しながら、子供が自然と受験勉強に取り組みやすい環境をつくることを目指しています。
