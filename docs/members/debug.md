# debug — デバッガー（全員の範囲の不具合を見つけて直す・確かめる）

## 人間向け（最初に読む）
- ミッション: DEMO.md の流れが main で端から端まで通るように、全員の範囲の不具合を見つけて直す（役割の細部は未定。まとめ役（lead）と相談して決める）
- 担当の場所: 自分だけのファイルは持たない。全員のファイルを見て、不具合を直す（直す前に持ち主に知らせる）
- 動作確認: `npm run dev`（.env は MOCK=1）で http://localhost:3000 を開く。API は `npm run api -- <契約名>` で叩く
- 詰まったら: 30分で解決しなければまとめ役（lead）に声をかける / `blocked` Issue

## 触るときの約束
- 他の人のファイルを直すときは、先にその持ち主に Issue かコメントで知らせる（同じファイルを2人が同時に直すと衝突する）
- 契約（contracts/）を変えるときは lead に知らせ、contracts/CHANGELOG.md に1行足す（docs/rules/changes.md）
- つなぎ役（契約の窓口）とまとめ役（同期点の進行）は lead のまま

## ステップ（1つ = 30〜60分 = AIへの1回の依頼 = 1PR）
印は付けない。完了は「マージ済み PR のブランチ名 `<自分のid>/S<番号>-…`」から自動で判定され、`npm run now` に ✓ / …（マージ待ち）/ ・（未着手）で出る。
ステップ表にない不具合直しは `npm run step -- X <英語名> --adhoc "目的"` で始める。
