# SelfLock のライセンス保管先の方針

根拠: `使用言語.md` の「8. SelfLockの利用方針」。SelfLock（https://github.com/EtashTyagi/SelfLock）は MIT License。コードを再利用する場合は、MIT の著作権表示とライセンス全文を保持する、と決まっている。

## 決まっていること（既存資料にある）
- 再利用するのは Kotlin 側（使用時間の計測・アプリ起動検出・ブロックなど）。既存 UI は原則再利用しない。
- 再利用したコードには、MIT の著作権表示とライセンス全文を付ける。
- Kotlin の自作部分は `modules/kit-native/` に置く（`docs/rules/stack.md`）。

## 方針（案。保管先の場所そのものは資料に根拠がないため未決）
- SelfLock のコードを1行でも取り込む前に、ライセンス全文（SelfLock の `LICENSE` の写し）と著作権表示を保管する。取り込まなければ保管は不要だが、「参考にしただけ」と取り込みの境目は取り込む人が PR に書く。
- 取り込んだファイルには、先頭コメントに出典（SelfLock の URL・取り込んだ時点のコミット）と「MIT License」を書く。
- 候補の保管先:
  - A. `modules/kit-native/LICENSE-SelfLock`（再利用する Kotlin の隣。取り込み先と一緒に動く）
  - B. `docs/design/`（人間確認領域。確認はしやすいが、アプリには同梱されない）
  - 配布するアプリ（APK）に表示する必要があるかは、MIT が求めるのが「写しに著作権表示と許諾文を含めること」である点から、配るなら同梱が安全。アプリ内の「ライセンス」画面で出すかは未決。
