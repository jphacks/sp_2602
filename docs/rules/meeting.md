# 会議の録音 → 要件の更新

リアルタイムでなくてよい。**会議（同期点）ごと**に回す。

1. 録音する（スマホで可）。
2. 文字起こしする（例: kotoba-whisper / faster-whisper をローカルで。手段は問わない）。
3. 文字起こし全文を AI に渡し、下のプロンプトで分類させる。
4. 出力を人が録音と照らして直し、`docs/requirements/decisions.md` と `open.md` を更新する PR を出す。
5. 契約に関わる決定は change-request Issue にする（直接 contracts/ を変えない）。

## 分類プロンプト
```
以下は開発チームの会議の文字起こしです。発言を次の5つに分類し、Markdown の箇条書きで出力してください。
推測で補わず、文字起こしにないことは書かないでください。誰の発言か分かれば (名前) を付けてください。

## 決定（decisions.md に追記するもの）
## 未決（open.md に追記するもの。決める人と期限が分かれば書く）
## 要求の変更（DEMO.md / 契約に影響しそうなもの。change-request の候補）
## 制約（時間・技術・ルール上の制限）
## 担当（誰が何をいつまでに）

既存の決定: <decisions.md を貼る>
文字起こし: <全文>
```
