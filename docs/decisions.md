# 決めたことの記録

「なぜこうなっているのか」を後から追えるように、決めたことを1行ずつ残します。
**決まったことは消さずに足していきます。** 変えたときは古い行を消さず、新しい行を足して「◯◯ の行を置き換える」と書きます。

まだ決まっていないことは [open-questions.md](open-questions.md) にあります。
テストの名前は `ファイル › テストの名前` の形で書きます（テストの名前で検索すると見つかります）。

## 足し方

1. 下の表の最後に1行足す。列は「番号・いつ・何を決めたか・なぜ・確かめるテスト」。
2. 番号は、人間が決めた仕様の質問なら `Q<番号>`、作る途中で決めたことなら `D-<番号>`（続きの番号）。
3. 「なぜ」は1〜2文で。資料（MVP_SPEC の章・Figma の番号・Q の番号）があれば書く。
4. 確かめるテストがなければ「なし」と書き、なぜないか（画面だけで決まる・React の中にある など）を添える。テストを足したら書き換える。
5. 仮の値で決めたもの（あとで変わるかもしれないもの）は「（仮）」を付け、[open-questions.md](open-questions.md) にも同じ項目を置く。決まったら open-questions.md から消し、ここの「（仮）」を外す。
6. コードにも同じことをコメントで書く（`TODO(未決):` が付いていれば外す）。
