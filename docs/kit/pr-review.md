# PR の AI 自動レビュー（Codex）を有効にする

PR を出したとき、Codex が差分を読んで、バグ・仕様とのずれ・コンフリクト解決の取りこぼしを指摘する。**設定は GitHub と Codex の画面で人間が1回行う**（AI にはできない）。レビューが読む観点は、このリポジトリの `AGENTS.md` の「Review guidelines」に書いてある。

## 有効にする手順（リポジトリの管理者が1回）
1. Codex の設定画面（chatgpt.com/codex の設定）を開き、GitHub と連携して、このリポジトリを接続する。
2. 「Code review」を有効にする。PR のたびに自動でレビューさせたいときは「自動レビュー」も有効にする。
3. 試しに PR を1つ出し、数分後にレビューのコメントが付くことを確かめる。付かなければ、連携の権限（リポジトリへのアクセス）を見直す。

画面の名前や項目は変わることがある。迷ったら公式ドキュメント（developers.openai.com/codex）で確認する。

## 自動レビューを切っているとき
PR のコメントに `@codex review` と書くと、その PR だけレビューさせられる。コメントの先頭には自分の id を書く（例 `lead: @codex review`）。

## 何を見張るか
- コンフリクトの解決で、自分側と main 側の**両方の変更が残っているか**（片方が消えていないか）
- `contracts/` を変えたのに `contracts/CHANGELOG.md` に記録がないもの
- 他人の担当部分への変更の混入、テストの削除・skip
- 色や余白の直書きなど、`AGENTS.md` の約束事の違反

## できないこと・注意
- コンフリクトの検出そのものは GitHub の機能。競合があると PR に「This branch has conflicts」と出て、マージできない。直すときはスキル `resolve-conflicts` を使う。
- AI のレビューは補助。マージの前に、`npm run check`（CI）が通ることと、人間が差分を読むことは必須。
- AI のレビューは外れる（見落とす・誤って指摘する）ことがある。指摘が正しいかは、必ず自分で確かめてから直す。
